# Security

Security fixes apply to the latest Tune release. Advisories list affected
versions and the first version with the fix.

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/mikehostetler/tune/security/advisories/new).
Include the Tune version, runtime versions, expected effect, and steps that use
sample data. Use placeholders for credentials and omit private prompts and user
data. Coordinate public disclosure with the maintainer.
